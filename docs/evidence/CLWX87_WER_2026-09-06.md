  reference "three forty five" costs 3 errors on `daily-report` for both

  ("Tuna Pune" for Tunapuna, 30.8% on that clip) — exactly the vocabulary a
  principal dictates daily; a domain prompt/initial-prompt pass is the named
  next tuning lever if whisper is chosen.
